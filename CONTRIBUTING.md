# Contributing to AyuCase

Thank you for helping improve AyuCase, the patient case-taking and documentation MVP built for Smart India Hackathon problem statement SIH26047.

## Local setup

    npm install
    npm run dev

## Contribution guidelines

- Keep patient-facing language clear, accessible, and multilingual where practical.
- Preserve the doctor-in-the-loop safety model: AyuCase supports documentation and triage; it does not diagnose or prescribe.
- Keep changes focused and test the relevant flow before opening a pull request.
- Never commit patient data, credentials, API keys, or other secrets.

For larger changes, please open an issue or pull request describing the problem, the proposed approach, and how it was tested.
